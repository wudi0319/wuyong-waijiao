# 无用外交（v1.0）

像王权陨落的手机网页塔防：国王白天建造，晚上亲自上场，守住城堡。纯 HTML + Canvas 2D，无框架，可添加到主屏幕（PWA）。

在线玩：https://wudi0319.github.io/wuyong-waijiao/

## 玩法
- 选国王：红袍国王（红王）或蓝袍国王（蓝王）。
- 武器：长剑（近战，前方 180° 扇面）、飞斧（远程，射程 4）、战锤（范围重击，通关后解锁）。每把武器都有大招：旋风斩 / 飞斧风暴 / 震地一击。
- 白天建造城墙、城门、弹弓塔、刀斧营、弓箭营、菜园。每次建造和升级（1/2/3 级）都二选一一个路线。
- 城堡自带连弩，会自动射击靠近的敌人。升级城堡时先给连弩选一条路线（连弩 / 火油弹，快弦 / 远射，重弩 / 沥青减速），再选一个城堡加成。每局最多升 3 次。
- 刀斧兵（近战）和弓箭手（远程，射程 3.5）倒下后会在营地复活。「⚔️ 跟随」跟着国王走，「🚩 原地部署」守在插旗的位置。
- 守住 7 个晚上就通关。按剩余城堡血量、建筑损失和挑战获得 1–5 星，用星星兑换出发前加成。加成分国王、士兵、建筑、经济四类，可以挑战加难度换更多星。
- 城堡被攻破就输了。

## 文件
- `index.html` / `style.css`：界面
- `js/sprites.js`：国王、城堡、士兵、树等手绘矢量画法
- `js/data.js`：武器、加成、建筑、敌人、关卡数据
- `js/game.js`：模拟和画面
- `js/ui.js`：开始菜单、HUD、按钮、摇杆和键盘
- `sw.js`：离线缓存（缓存名带 `wuyong-` 前缀）

进度存在本机浏览器里（localStorage，键名带 `wywj-` 前缀），每个人看到的都是自己的进度。

电脑上：WASD 走路 · E 建造 / 升级城堡 · N 入夜 · 空格 放技能 · F 跟随/部署 · P 暂停
